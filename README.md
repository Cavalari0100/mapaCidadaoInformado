# 🗺️ Mapa Cidadão Informado

> Facilitando o acesso do cidadão a informações e portais públicos brasileiros.

O **Mapa Cidadão Informado** é um projeto open source e comunitário criado para facilitar a localização e o acesso a informações públicas.

Encontrar uma informação pública nem sempre é simples. Cada prefeitura, órgão ou entidade pode possuir diferentes portais, sistemas e caminhos para disponibilizar suas informações.

A proposta deste projeto é reunir esses caminhos em um único lugar, facilitando a navegação do cidadão até a **fonte oficial da informação**.

---

## 🎯 Objetivo

Criar uma plataforma simples que ajude o cidadão a encontrar:

- 🏛️ Prefeituras
- 💰 Portais da Transparência
- 📊 Dados públicos e dados abertos
- 📑 Licitações e contratos
- 👥 Informações sobre servidores públicos
- 🏗️ Obras públicas
- 📜 Diários Oficiais
- 📨 e-SIC / pedidos de acesso à informação
- 📢 Ouvidorias
- 🏛️ Câmaras Municipais
- ⚖️ Tribunais de Contas
- 📚 Guias sobre como encontrar e compreender informações públicas

---

## 💡 Por que este projeto existe?

Informações públicas são importantes para o exercício da cidadania, mas isso não significa que sejam fáceis de encontrar.

Um cidadão pode saber **o que quer descobrir**, mas não necessariamente saber:

> "Onde encontro essa informação?"

O Mapa Cidadão Informado busca diminuir essa distância.

Em vez de substituir os portais oficiais, o projeto procura **organizar e facilitar o caminho até eles**.

---

## 🧭 Como funciona?

Inicialmente, o projeto será baseado em informações e links para fontes públicas oficiais.

Por exemplo:

```text
Cidade X, Estado Y

├── 🏛️ Prefeitura
├── 💰 Portal da Transparência
├── 🏛️ Câmara Municipal
├── 📜 Diário Oficial
├── 📨 e-SIC
└── 📢 Ouvidoria
```

O projeto não pretende substituir essas fontes.

Sempre que possível, o usuário será direcionado para o **site ou sistema oficial responsável pela informação**.

## ⚖️ Independência

O Mapa Cidadão Informado é um projeto independente e não representa qualquer governo, partido político ou órgão público.

O projeto busca apresentar informações de forma neutra e priorizar fontes oficiais.

A finalidade é **facilitar o acesso à informação**, não determinar interpretações sobre os dados encontrados.
